# BUG-002: Manager maintenance detail missing manage controls

Date: 2026-01-26
Branch: main
Commit: 30742b437e193a1db2050f19815dfda884b5950d
Severity: High
Status: Resolved

## Summary
Manager users can open a maintenance request detail page, but the “Manage request” controls (status transition, assign staff, completion notes) do not render, blocking Phase 2 admin workflows.

## Environment
- Frontend: Vite preview build (`npm run build` + `npm run preview`)
- Backend: Django runserver on http://127.0.0.1:8000
- Base URL: http://127.0.0.1:4173

## Steps to Reproduce
1. Login as a manager user.
2. Navigate to `/maintenance/all`.
3. Click **Manage** on any request.

## Expected
The maintenance detail page shows the **Manage request** card with:
- Status transition dropdown
- Assign staff ID field
- Completion notes textarea

## Actual
The detail page shows request info (assigned staff, completion notes, status history), but the **Manage request** card is missing.

## Impact
Managers cannot update status, assign staff, or add completion notes via the UI, blocking Phase 2 workflows.

## Evidence
- UI smoke: manager detail page lacks “Manage request” controls.
- Local screenshot captured: `/tmp/phase2_manage_detail.png`.
